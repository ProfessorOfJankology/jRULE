Global property pool

Each source exposes rule parameters with current and previous values. Expand available source fields to browse nested response data and promote useful paths into friendly rule properties.

jAPI GET sources

A source only needs a name, jAPI endpoint and polling interval. Query strings are supported. Derived rule properties are created from observed fields in the Global pool.

Source configuration

Custom stored variables

Persistent values live in the global pool as current.variables.name / previous.variables.name. Rules can update them with the built-in variables.set action.

Variable

jAPI POST actions

Rules may invoke configured jAPI actions or the built-in variables.set action. Body templates can use {{ current.object.property }} and {{ args.value }}. The jAPI key is supplied automatically server-side. All actions require JRULE_ENABLE_ACTIONS=1.

Action configuration

Rules

Conditions use current.object.property, previous.object.property and meta.object.property.last_changed. Actions use configured jAPI action names.
